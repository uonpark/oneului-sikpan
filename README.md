# 오늘의 식판

급식실에서 식판을 채우며 영양소를 예측하고 확인하는 중학교 기술·가정 수업용 웹 학습 게임입니다.

- 사이트: https://uonpark.github.io/oneului-sikpan/
- 대상: 중학교 1·2학년, 노트북 브라우저 (로그인 없음)

## 기능

### 식단 짜기 미션 게임
1. 배식대에서 음식 20종을 끌어다 식판 5칸에 담고, 국자 수(양)를 조절합니다.
2. 식판에서 가장 부족한 영양소를 예측합니다.
3. 결과에서 5대 영양소별 양과 상태, 에너지 비율, 세 가지 기능 게이지를 확인합니다.
4. "고치러 가기"로 식판을 고치고, 고치기 전과 비교합니다.

### 내 식단 기록
- 달력에서 날짜를 고르고, 아침·점심·저녁 칸에 먹은 음식을 검색해 기록합니다 (초성 검색 가능).
- 급식, 분식·외식, 편의점·간식, 과일·음료 76종을 검색할 수 있습니다.
- 하루 영양 합계를 하루 권장량과 비교합니다.
- 기록은 그 브라우저(localStorage)에만 저장됩니다. 다른 노트북이나 다른 브라우저에서는 보이지 않습니다.

## 영양 판정 기준

2025 한국인 영양소 섭취기준 12~14세 남녀 평균을 씁니다. 한 끼는 하루 기준의 3분의 1입니다.

| 영양소 | 기준 |
|---|---|
| 탄수화물 · 지방 | 에너지 적정비율 (탄수화물 50~65%, 지방 15~30%) |
| 단백질 · 칼슘 · 비타민 C | 권장섭취량 |
| 에너지 | 필요추정량 |

기준의 60% 미만은 부족, 90% 미만은 조금 부족, 적정 범위 위 끝을 넘으면 많음입니다.
무기질은 칼슘, 비타민은 비타민 C로만 계산합니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 서버와 로그인은 필요 없습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 디자인 |
| `script.js` | 미션 게임 동작과 영양 계산 |
| `record.js` | 내 식단 기록 (달력, 검색, 저장) |
| `sound.js` | 8비트 효과음 |
| `data.js` | 음식 영양값과 섭취기준 |

## 사용한 자료

- 음식 영양값: 식품의약품안전처 [K-FIND 식품영양성분 데이터베이스](https://various.foodsafetykorea.go.kr/nutrient/)
- 섭취기준: 2025 한국인 영양소 섭취기준 (보건복지부)
- 글꼴: [갈무리(Galmuri)](https://github.com/quiple/galmuri), SIL Open Font License 1.1 (`fonts/OFL.md`)
- 1인분 분량 중 `data.js`에 "확인 필요"로 표시한 값은 공식 자료로 확인하지 못한 값입니다.
